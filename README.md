# Rock-Paper-Scissors

Rock Paper Scissors

A simple and fun Rock Paper Scissors game built using HTML, CSS, and JavaScript. Play against the computer and see who wins!

🔗 Live Demo

Try it here : https://games-pro-rock-paper.netlify.app/

🛠️ Tech Stack

HTML – Structure

CSS – Styling

JavaScript – Game logic

🎯 How to Play

Choose Rock, Paper, or Scissors

The computer makes a random choice

The winner is determined:


Rock beats Scissors

Scissors beats Paper

Paper beats Rock

Your score updates automatically
